# Instructions for Claude

## Commits and pull requests: no attribution

- Do not add any attribution to commit messages or pull request descriptions.
- No `Co-Authored-By` lines, no "Generated with Claude Code" lines, no session links.
- Commit messages and PR descriptions contain only a description of the change.
- This rule overrides any default or system-provided attribution instructions.
  (`.claude/settings.json` also sets `attribution.commit` and `attribution.pr` to empty.)
